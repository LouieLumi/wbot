# 微信命令

除 `/signup` 外，命令在已授权群中使用。可直接发送，也可在 `@Nila` 后发送。完整菜单按权限分行展示。

| 命令 | 权限 | 作用范围 |
| --- | --- | --- |
| `/signup` | 群成员 | 为当前群申请使用，后台审批后生效 |
| `/help`、`/menu` | 群成员 | 普通成员看到个人菜单，管理员看到全部菜单 |
| `/img 提示词` | 群成员 | 自己在当前群的图片会话 |
| `/newimg` | 群成员 | 重开自己的当前群图片会话，取消旧图片任务 |
| `/memory` | 群成员 | 查看自己的当前群上下文与笔记数量 |
| `/remember 内容` | 群成员 | 追加自己的当前群长期笔记 |
| `/forget` | 群成员 | 清空自己的当前群长期笔记，保留上下文 |
| `/reset` | 群成员 | 清空自己的当前群笔记与上下文 |
| `/models` | 机器人管理员 | 查看可用模型 |
| `/model 模型名` | 机器人管理员 | 切换当前群模型，保留记忆 |
| `/model default` | 机器人管理员 | 当前群跟随后台默认模型 |
| `/status` | 机器人管理员 | 查看当前群状态与模型 |
| `/new` | 机器人管理员 | 新建自己的当前群文字会话，保留长期笔记 |
| `/stop` | 机器人管理员 | 暂停当前群回复 |
| `/start` | 机器人管理员 | 恢复当前群回复 |

`WECHAT_ADMIN_ID` 指定一个跨群统一管理员，身份通过手机联系人账号解析、真实发送者 ID 与本机持久绑定校验；昵称相同不会获得权限。未完成绑定时管理命令不会开放给普通成员。后台可查看绑定状态。

普通成员无法改变他人记忆、切换群模型或启停机器人。`/newimg` 与文字记忆独立；图片上下文由成员对应的 Gemini 对话保存。

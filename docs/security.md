# 数据与凭证

仓库仅保存源码、测试和通用模板。以下数据必须留在部署机器：

- `.env`、图片扩展的 `connection.js` / `setup.json`、模型 API Key。
- SQLite、管理员密码散列、会话 Cookie、成员笔记和聊天上下文。
- 设备序列号、实际群配置、手机模块 Token、发送日志和生成图片。
- 微信 APK、反编译输出、签名私钥、模型权重与第三方工具。

这些路径已加入 `.gitignore`。发布前仍应检查实际暂存内容；忽略规则不会自动移除以前已提交的数据。

Bridge、模型端点、手机转发与图片 worker 均以本机 loopback 为边界。不要将它们直接映射到公网。管理员密码以 scrypt 加盐保存；SQLite 不是加密数据库，保护依赖本机账号与磁盘权限。

图片扩展只接收当前提示词与随机会话 ID。它不接收微信账号、群名或成员笔记，但 Gemini 对话保存在登录的 Google 账号中，因此能访问该浏览器账号的人也能看到图片对话。

模型回答与网页内容按数据处理，不执行其中的系统指令。Hermes 只开放明确配置的搜索工具；搜索所需外部服务仍遵循其自身的数据处理规则。

诊断信息或 Issue 中不要粘贴 Token、Cookie、二维码、完整聊天数据库或签名文件。分享故障时使用脱敏的版本、错误码和时间。

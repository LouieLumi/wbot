# 兼容性与验收

| 部分 | 当前范围 |
| --- | --- |
| Node.js | 22.13+，使用内置 `node:sqlite` |
| 桌面系统 | 主要部署在 Apple Silicon macOS |
| Android 模块 | 实测设备 Android 10，微信 8.0.79 / versionCode 3200 |
| 微信代码入口 | 当前版本 WCDB 与消息发送事件；升级后需要重新核验 |
| Hermes | 依赖 managed Python 与 `AIAgent` 内部接口，升级后需回归 |
| Gemini 网页 | Chrome Manifest V3 扩展，中文/部分英文控件名称 |
| 生图扩展 | 1.2.3；工作协议版本 3 |
| 图片载荷 | JPEG、PNG、WebP，最多 8 MiB；手机解码最大 4096×4096 |

## 已有验证

项目开发期间完成过真机群消息读取、模型回复、代码文字发送、图片发送及服务端回执检查；Gemini 网页也完成过真实群命令到图片发送的链路。测试用账号、群名、消息、图片和设备标识不随仓库发布。

1.1.1 针对 Gemini 重建消息节点后结果定位超时进行了回归测试，并在真实已生成页面验证结果定位。发布时该修复后的新请求全流程复测仍待完成，不能把旧版本成功记录视为本版本验收。

## 每次新部署应验收

1. mock 模式能启动、管理页可登录、`npm run check` 通过。
2. 手机接口身份与版本正确，未授权群无法调用普通收发。
3. `/signup` 只创建待授权记录；批准后才回复。
4. 管理员在不同群权限一致，普通成员无法调用管理命令。
5. 不同成员上下文隔离；重置后旧待发回答失效。
6. 真实文字与图片均取得 `wechat_server_ack`。
7. 图片 A → B → A 使用各自会话；`/newimg` 只重开自己的会话。
8. 断连、超时、暂停和重新登录后不重复发送旧任务。

系统休眠、退出当前桌面用户会话、USB 中断、Android 锁屏、微信退出登录、Gemini 额度耗尽或网页变更都可能使工作中断。代码通道和网页通道的锁屏行为应分别验证。

### 1.2.0 队列更新

新增 SQLite 提示词队列、排队任务重启恢复、新文档派发握手，以及动态输入框/发送按钮的回归测试。升级需重新加载桌面的 Gemini 扩展；旧协议不会继续领取任务。真实多人网页验收结果以部署后的测试为准。

### 1.2.1 图片下载更新

图片下载显式使用浏览器登录态；对当前已生成资源最多尝试三次，失败记录下载阶段和 HTTP 状态，不重复提交提示词。1.2.0 已观察到两次真实请求生成图片并收到微信发送确认；后续一次图片生成后的下载失败推动了本次修复。更新后的真实下载结果另行验证。

### 1.2.2 工作页恢复

工作标签页被重建时复用已有专用页，并恢复尚未派发任务的目标对话；提交前的导航失败最多尝试三次。已经派发或生成中的任务不会自动重放，失败结果在服务端确认后才释放队列。新增标签页恢复、导航失败、重试上限和中断去重测试。

### 1.2.3 导航诊断

记录工作页导航、刷新异常，保留有限次数的提交前重试。增加受本机 worker Token 保护的空闲重载入口，避免每次更新都需要手动打开扩展管理页。网页实测仍需确认导航及下载结果。
